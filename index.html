Cấu hình Trí tuệ nhân tạo Gemini AI

Ứng dụng sử dụng mô hình Gemini 1.5 Flash của Google để thực hiện nhận diện văn bản OCR và trích xuất dữ liệu tự động từ tài liệu scan của bạn.

Lưu ý: API Key của bạn được lưu an toàn trực tiếp trên trình duyệt của bạn (LocalStorage) và không bao giờ gửi đi bất kỳ server trung gian nào khác ngoài API chính thức của Google.
Cách lấy Gemini API Key miễn phí:
  1. Truy cập trang web Google AI Studio.
  2. Đăng nhập bằng tài khoản Google của bạn.
  3. Nhấp vào nút "Get API key" ở thanh menu bên trái.
  4. Nhấp "Create API key", chọn dự án và copy mã Key được cấp rồi dán vào ô bên trên.

Đồng bộ Google Sheets & Drive API

Kết nối ứng dụng với trang tính Google Sheets và lưu trữ tệp trên Google Drive của bạn thông qua Google Apps Script.

Dán đường dẫn Deployment Web App của Apps Script sau khi bạn đã xuất bản dưới dạng Web App. Xem chi tiết file hướng dẫn đính kèm.
Quy trình liên kết với Google Drive của bạn:
1

Copy mã nguồn trong tệp google_apps_script.js được tạo trong dự án này.

2

Vào Google Sheet của bạn -> Chọn Tiện ích mở rộng -> Apps Script -> Dán đè mã nguồn vào file Code.gs rồi bấm lưu.

3

Nhấp Triển khai (Deploy) -> Triển khai mới (New deployment) -> Loại: Ứng dụng web (Web app) -> Cấp quyền cho "Bất kỳ ai (Anyone)" truy cập -> Deploy và copy URL điền vào ô bên trên.
